## Implementation notes (conservative interpretations logged per spec §0.3)

| Ref | Ambiguity | Conservative interpretation taken |
|-----|-----------|-----------------------------------|
| A | Spec declares `claims` append-only **and** defines a `review_status` workflow on claims. | Claim *content* is frozen by trigger; only `review_status` may be updated. Alternative (separate review-events table) flagged in data_dictionary.md. |
| B | Spec gives one column template for all five aggregate-context tables, but `classification_concordance` is a code mapping. | Concordance gets from/to system+code columns; the four true aggregate tables follow the template verbatim. |
| C | `ingestion_runs` is append-only but has `finished_at`/`status`. | Run rows are inserted once, at completion, with final status — no in-place updates. |
| D | Byte-identical re-export vs manifest timestamp. | Data files are strictly deterministic; the manifest timestamp honors `SOURCE_DATE_EPOCH` when set (tests set it), otherwise uses current UTC time. |
| E | Sites lacking a stated admin area but carrying source-stated coordinates. | Province derived by point-in-polygon against Natural Earth reference geometry, recorded in facility notes as a *derivation from stated coordinates* — never as a source assertion. |
| F | Incidents without published coordinates whose title names a registered facility. | `link_incident_facilities` (STATUS: PROPOSED): manual_override decisions copy the facility's source-stated coordinates only when every distinctive (non-generic, non-province-name) token of the facility name appears in the incident title, provinces match, and exactly one candidate exists; ambiguity always loses. Precision recorded `facility_approximate`; decisions cite the facility's source claim and are supersedable. |
| G | Records whose province is known but whose coordinates are not published (46 of 51). Drawing nothing hides 90% of the register from the map; drawing a pin implies precision the sources do not give. | Rendered as a **hollow, ringed** carnation on a computed interior point of the province, never a filled pin, per `coordinate_precisions.csv` (`province_centroid` = "never render as exact pin"). The legend and the tooltip both say "province-level; exact site not published". The anchor is an area-weighted polygon interior point, **not** `province_centroids.csv` (those are Wikidata P625 province *seats*, i.e. the capital city, which would imply the accident happened there). Marks for located records are drawn solid and separately, so no record is counted twice. |
| H | The province map coloured absolute counts on an area-varying base, and no exposure denominator exists in the repository (open questions #6, #18). | Proportional symbols became the primary encoding (correct for counts); the choropleth is retained as a secondary "Shaded provinces" view with fixed breaks re-cut to the real distribution (1/5/20/50/300+, every class occupied) and a caption stating that a large province is not a worse one. No rate is computed. Display geometry moved to an Albers Equal Area Conic (standard parallels 37.5N/41.5N) because colouring areas demands an equal-area projection; the previous equirectangular sheared the country ~10% north to south. |
